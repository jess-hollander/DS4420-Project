# Autoregressive Model (AR(p))

This model predicts NBA team scores using previous game scores.

## Model Results

- Selected lag order: 8
- Training seasons: 2021-22 to 2024-25
- Test season: 2025-26
- Games evaluated: 1,230
- Accuracy: 54.88%
- MAE: 10.53 points
- RMSE: 13.19 points

The model is implemented in AR_Model.ipynb using statsmodels.
